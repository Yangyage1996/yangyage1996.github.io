# Yage Yang · Academic Profile

Personal academic website for **Yage Yang (杨亚格)**, a PhD student at Beijing Jiaotong University researching human–computer interaction and human–automation function allocation for intelligent dispatching in urban rail transit.

Intended URL: https://yangyage1996.github.io/

## Files

- `index.html`: biography, research interests, and affiliations.
- `styles.css`: responsive styling, keyboard focus states, and print styles.
- `favicon.svg`: text-based site icon.
- `.nojekyll`: serves the static files directly on GitHub Pages.

No build step, external font service, analytics, or JavaScript is required.

## GitHub Pages

Create the public repository `Yangyage1996/yangyage1996.github.io` and upload these files to its root. In **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/ (root)**, and save.

This is a personal academic website displaying institutional affiliations. It is not a university-hosted official profile. No unpublished paper, experimental dataset, private contact details, or credentials are included.

## Maintenance

Edit `index.html` to update biographical details. Add an institutional email or verified publication entries when supplied by the owner. Update the footer date after changes.
